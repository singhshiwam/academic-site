# Shiwam Singh, academic website

Static site for GitHub Pages. No framework, no build server: plain HTML, CSS and JavaScript, generated by one Python script.

## Layout

| Path | What it is | Edit by hand? |
|---|---|---|
| `src/pages/*.html` | The text of each page | Yes. This is where content lives. |
| `src/layout.html` | Header, footer and `<head>` shared by every page | Yes |
| `assets/css/site.css` | All styling, including the day and night palettes | Yes |
| `assets/js/site.js` | Day/night switch, menu, search (Ctrl K), citation boxes, filters | Yes |
| `assets/js/hero.js` | The animated valley on the home page | Yes |
| `assets/js/explorer.js` | Stability function explorer on the Research page | Yes |
| `assets/js/nowcast.js` | Current weather at the visitor's location (Open-Meteo) | Yes |
| `assets/js/gallery.js` | Gallery albums and the full-screen viewer | Yes |
| `gallery/gallery.json` | Album list, titles, captions | Captions, yes |
| `index.html`, `about.html`, ... at the root | Finished pages | No, they are generated |
| `assets/js/search-index.js`, `sitemap.xml`, `robots.txt` | Search entries and search-engine files | No, generated |

## Making a change

1. Edit the page in `src/pages/`, or the CSS and JS in `assets/`.
2. Run `python3 tools/build.py`. It rebuilds every page, the search index and the cache-busting version string.
3. Preview with `python3 -m http.server` and open http://localhost:8000.
4. Commit and push. Cloudflare Pages redeploys in about a minute. Hard refresh with Ctrl+Shift+R.

Anything with a `data-find="Kind|Title|Description"` attribute and an `id` shows up in the site search.

## Adding photos

```
pip3 install pillow
python3 tools/add_photos.py egu-2026 photo1.jpg photo2.jpg \
    --title "EGU General Assembly 2026" --date 2026-05-05 \
    --place "Vienna, Austria" --category conference
```

Categories: `field`, `conference`, `school`, `campus`, `travel`. Photos are resized to 2000 px with 700 px thumbnails, and camera metadata (including GPS) is dropped. Write captions in `gallery/gallery.json`. Run the same command with an existing album id to add more photos to it. No rebuild is needed for photos.

## Hosting and address

The site is served by Cloudflare Pages at https://shiwam-singh.dev, deployed from the `main` branch of this repository. Every push redeploys it in about a minute. Cloudflare settings for the project: framework preset None, build command empty, build output directory `/`. The pages are committed already built, so Cloudflare runs nothing.

- `_headers` sets response headers on Cloudflare (security basics, long caching for fonts).
- `404.html` is what Cloudflare shows for an address that does not exist.
- `sitemap.xml` and `robots.txt` are written by `tools/build.py`.

`BASE_URL` in `tools/build.py` is used for the canonical link, social previews and the sitemap. Change it if the site moves to another address, then rebuild.
